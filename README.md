# Agent OS — Drawing Set 01

A one-page schematic of the proposed agent OS for a solo web studio: seven scheduled stations, one shared state file, one human approval gate.

Static HTML, no build step. Open `index.html` or view it at the GitHub Pages URL.

Sheets:

- 01 General arrangement — the plan view of the whole rig
- 02 Agent schedule — what each station takes, gives, and is not allowed to do alone
- 03 Duty cycle — the 24-hour rotation and the weekly digest
- 04 Erection sequence — the order to build it, and what each week must prove
- 05 Drawing notes — what the machine is not, and what it needs first

Hover or focus a station in sheet 01 to trace its row in the schedule; click it to jump there.
